# 周囲より低い地形チェッカー

国土地理院の標高タイルをブラウザ内で解析し、指定した半径の周囲と比べて低い地形を色で見つけやすくする静的Webツールです。

## できること

- 地図をドラッグ、ホイール、ピンチ、地図内ボタンで移動し、ズーム18まで拡大
- 初回表示、地図移動、ズーム、判定条件の変更後に、停止を待って自動解析
- 判定半径を250m、500m、1km、10km、50km、100km、150km、200km、300kmから選択
- ズーム5〜18の全倍率で、表示範囲に合わせた解像度の窪地解析を継続
- 周囲平均との差が表示下限以上の場所だけを4段階で表示
- 地図上の地点を選び、標高、周囲平均、周囲との差を確認
- 標準地図、淡色地図、陰影起伏図を切り替え、背景地図の濃さを0〜100%で調整
- 地形をデフォルトの白黒（陰影起伏図）またはカラー（色別標高図）で重ね、濃さを調整
- 地図左下の縮尺バーで現在の表示距離を確認
- 「リンク取得」で、表示中心、ズーム、判定条件、地図・地形・窪地色の表示設定、選択地点を復元できる共有URLをコピー
- 「PNG保存」で、現在の地図を凡例、縮尺、出典、注意書き付きのPNG画像として端末へ保存
- Bousai Wx Lab本体と統一したネイビーからブルーの滑らかなヘッダーと、高密度の操作パネルからブログとXへ移動

表示値は、地点から指定半径だけ離れた最大16方向の標高の平均と、地点の標高との差を独自に計算した参考値です。標高欠測を除外し、半径に応じて最低4〜10方向の標高がある格子だけを計算します。洪水、内水、津波、土砂災害等の危険度や浸水深を表すものではありません。避難や土地利用の判断には、自治体のハザードマップ、気象庁、国土交通省等の公式情報と現地状況を確認してください。

## データと通信

- 標準地図・淡色地図・陰影起伏図: 国土地理院「地理院タイル」
- 標高: 国土地理院「標高タイル（DEM5A、DEM5B、DEM5C、DEM10B）」
- 解析: すべて利用者のブラウザ内で実行

背景地図は正式提供範囲のズーム18まで表示します。色別標高図はズーム15、陰影起伏図はズーム16が配信上限のため、それより拡大した画面では同じタイルを拡大表示します。標高判定は表示倍率と判定半径に応じ、ズーム5〜14相当の標高タイルから通信量の上限内で最も細かいものを自動選択します。解析に使った1画素あたりのおおよその距離は地図上へ表示し、元データより細かい精度を示しません。色別標高図の海域部は海上保安庁海洋情報部の資料を使用して作成されています。

本ツールは位置情報API、住所入力、Cookie、Web Storage、アクセス解析を使用しません。表示範囲に対応する地図・標高タイルの取得時には、利用者のブラウザから国土地理院のサーバーへ通信します。ブログとXには、利用者がヘッダーのリンクを押した時だけ移動します。

共有URLは利用者が「リンク取得」を押した時にだけ生成し、表示中心の緯度・経度、ズーム、判定・表示設定、選択地点がある場合はその座標を含めてクリップボードへコピーします。これらを本ツールのサーバー、Cookie、ブラウザ保存領域へ保存しません。URLを受け取った人には表示位置が伝わるため、個人宅などの場所を共有する前に確認してください。PNGも利用者のブラウザ内で生成し、外部サーバーへ送信しません。

## ブランド画像

- ブログ導線とfaviconには、Bousai Wx Labで採用済みのユーザー提供サイトアイコンの512px公開版を、再加工せず同一bytesで自己ホストして使用
- 公開ファイルは `assets/bousaiwxlab-site-icon.png`、512×512px、RGB PNG、266,670 bytes、SHA-256 `f2258fc48adea8bdcf175699fb08b434b039c0aee83a4439c181741f3c2a4c9e`
- EXIF/XMPは色空間・画像寸法以外の人物名、位置情報、端末情報を含まないことを確認
- X導線は[公式ブランドツールキット](https://about.x.com/ja/who-we-are/brand-toolkit)の黒地・白ロゴ表現に合わせたベクター形状を、リンク識別用途だけに使用
- Open Graph／Xカード画像はユーザー提供PNGを無加工で自己ホストし、`assets/terrain-depression-share-card.png`、1731×909px、RGB PNG、2,587,161 bytes、SHA-256 `d62c3ad73ac14bd46fa6300b155d3d1243cd20f3404c5a7f8fab1699e2615afd`
- カード画像のPNGメタデータはsRGBと画像寸法だけで、人物名、位置情報、撮影日時、端末情報、テキストコメントを含まないことを確認

## ローカル確認

```bash
python3 -m http.server 8765
```

`http://127.0.0.1:8765/` を開きます。HTMLファイルをブラウザで直接開く方法では、安全制約により標高タイルを取得できません。

## 公開前検査

```bash
python3 scripts/build_release_manifest.py
python3 scripts/privacy_gate.py
node tests/terrain.test.mjs
```

`privacy_gate.py` は公開allowlist、ファイル内容、外部通信先、危険なブラウザAPI、Gitの全objectとcommit identityを検査します。ブランドPNGは許可した1ファイルのbytes、SHA-256、PNG構造、CRC、寸法、bit depth、color typeが完全一致する場合だけ認めます。検査不能または不一致は失敗として扱います。
