# 周囲より低い地形チェッカー

国土地理院の標高タイルをブラウザ内で解析し、指定した半径の周囲と比べて低い地形を色で見つけやすくする静的Webツールです。

## できること

- 地図をドラッグ、ホイール、ピンチ、地図内ボタンで移動し、ズーム18まで拡大
- 判定半径を250m、500m、1kmから選択
- 周囲平均との差が表示下限以上の場所だけを4段階で表示
- 地図上の地点を選び、標高、周囲平均、周囲との差を確認
- 標準地図、淡色地図、陰影起伏図を切り替え
- 地形をカラー（色別標高図）または白黒（陰影起伏図）で重ね、濃さを調整
- ヘッダーからBousai Wx LabのブログとXへ移動

表示値は、地点から指定半径だけ離れた16方向の標高の平均と、地点の標高との差を独自に計算した参考値です。洪水、内水、津波、土砂災害等の危険度や浸水深を表すものではありません。避難や土地利用の判断には、自治体のハザードマップ、気象庁、国土交通省等の公式情報と現地状況を確認してください。

## データと通信

- 標準地図・淡色地図・陰影起伏図: 国土地理院「地理院タイル」
- 標高: 国土地理院「標高タイル（DEM5A、DEM5B、DEM5C、DEM10B）」
- 解析: すべて利用者のブラウザ内で実行

背景地図は正式提供範囲のズーム18まで表示します。色別標高図はズーム15、陰影起伏図はズーム16が配信上限のため、それより拡大した画面では同じタイルを拡大表示します。標高判定はズーム14相当の標高タイルを使い、画面の拡大によって元データの解像度が上がるわけではありません。色別標高図の海域部は海上保安庁海洋情報部の資料を使用して作成されています。

本ツールは位置情報API、住所入力、Cookie、Web Storage、アクセス解析を使用しません。表示範囲に対応する地図・標高タイルの取得時には、利用者のブラウザから国土地理院のサーバーへ通信します。ブログとXには、利用者がヘッダーのリンクを押した時だけ移動します。

## ローカル確認

```bash
python3 -m http.server 8765
```

`http://127.0.0.1:8765/` を開きます。HTMLファイルをブラウザで直接開く方法では、安全制約により標高タイルを取得できません。

## 公開前検査

```bash
python3 scripts/build_release_manifest.py
python3 scripts/privacy_gate.py
node tests/terrain.test.mjs
```

`privacy_gate.py` は公開allowlist、ファイル内容、外部通信先、危険なブラウザAPI、Gitの全objectとcommit identityを検査します。検査不能または不一致は失敗として扱います。

本リポジトリの独自コードについて、明示的な利用許諾は設定していません。地理院タイルは国土地理院コンテンツ利用規約に従って利用してください。地図画面には出典を常時表示しています。
