# 周囲より低い地形チェッカー

国土地理院の標高タイルをブラウザ内で解析し、指定した半径の周囲と比べて低い地形を色で見つけやすくする静的Webツールです。

## できること

- 地図をドラッグ、ホイール、ピンチ、地図内ボタンで移動し、ズーム18まで拡大
- 初回表示、地図移動、ズーム、判定条件の変更後に、停止を待って自動解析
- 判定半径を250m、500m、1km、10km、50km、100km、150km、200km、300kmから選択
- ズーム5〜18で、半径が集計格子8画素以上、地点の元データ2画素以上となる倍率だけ解析。小半径を広域表示した場合は拡大案内
- 周囲より低い量が表示下限以上の場所だけを、0.5–1m、1–1.5m、1.5–2m、2–3m、3–4m、4–5m、5–10m、10m以上の8段階で表示
- 地図上の地点を選び、その座標を格子中心へ丸めず再計算した標高、周囲平均、標高差（地点−周囲平均）を確認。周囲より低い地点は負の値で表示
- 標準地図、淡色地図、陰影起伏図を切り替え、背景地図の濃さを0〜100%で調整
- 地形をデフォルトの白黒（陰影起伏図）またはカラー（色別標高図）で重ね、濃さを調整
- 地図中心の「＋」と、画面中心で見た判定半径の目安となる円を、それぞれ独立して表示・非表示
- 地図左下の縮尺バーで現在の表示距離を確認
- 「リンク取得」で、表示中心、ズーム、判定条件、地図・地形・窪地色・中心ガイドの表示設定、選択地点を復元できる共有URLをコピー
- 「PNG保存」で、現在の地図を凡例、縮尺、出典、注意書き付きのPNG画像として端末へ保存
- Bousai Wx Lab本体と統一したネイビーからブルーの滑らかなヘッダーと、高密度の操作パネルからブログとXへ移動

## 円内平均の定義

各表示格子を中心とする円の内側について、標高×陸地面積の合計を陸地面積の合計で割ります。円周の標本、方位区画、乱数、正方形やガウス分布への置換は使用しません。地形の各画素の面積は緯度に応じた球面面積で重み付けします。標高0m・負の標高も有効です。海と標高欠測は0m扱いせず、分子・分母の両方から除きます。独立した陸海ポリゴンは使わず、標高タイルの有効範囲を陸地の近似とします。湖など水面の標高が提供される場所は含まれます。

- 円は半径6,371,008.8mの球面上の距離で定義。楕円体測地線ではありません。
- 円の境界は集計格子の中心が円内かどうかで判定する離散近似です。格子より細かな境界の厳密切断ではありません。
- 半径50km以上は、国内DEM10Bのズーム12（日本付近で約26〜37m）全有効画素から作った「標高合計と陸地面積」の事前集計を使用。平均値だけを再平均せず、細かな陸地の寄与を保持します。
- 半径200・300kmは最大ズーム8、100・150kmは9、50kmは10の集計格子を使用。広い表示範囲ではさらに集約します。集計格子間隔は画面内の説明に表示します。
- 半径10km以下は必要な範囲の標高を直接取得して同じ円内積分を実施。表示倍率・必要な範囲に応じて解像度を選びます。低倍率ほど細かな地形は確認できません。
- 地図表示の標高と円内平均の集計解像度は分離。クリックした地点の標高は最大DEM1Aズーム17で再取得し、同じ円内平均と比較します。共有地点も再計算します。
- 集計対象の中心は東経118〜154度、北緯20〜48度。300kmの円全体に必要な範囲を含む東経114〜160度、北緯17〜51度のデータを用意しています。
- 国境を越えた陸地は国土地理院の全球標高（DEMGM、元データ約500m）で補完します。国内データが存在する全球画素には追加せず、国内の海岸を粗い全球データで埋めません。国外は国内と同じ精度ではありません。
- 取得失敗や必要範囲不足で部分平均を表示しません。判定不能・対象範囲外は灰色、小半径に不十分な倍率は拡大案内、海・欠測は透明です。着色下限未満の陸地も透明なので「無着色＝安全」ではありません。

選択地点の標高差は「地点−円内陸地平均」で、周囲より低い場合は負です。地図と凡例は低い量を正の値で表します。ガイド円は画面中心の比較範囲を示しますが、計算は各表示格子それぞれを中心として行います。

洪水、内水、津波、土砂災害等の危険度や浸水深を示すツールではありません。避難や土地利用には自治体のハザードマップ等の公式情報と現地状況を確認してください。

## 計算と速度

Web Workerで円の各行の陸地面積・標高合計を累積し、円内の区間和をまとめて求めます。地図操作を計算で占有しません。読み込み済みデータはメモリー内だけで再利用し、着色下限・透明度の変更では平均を再取得しません。通信には20秒の上限を設けます。

約1秒の応答は最適化目標であり、全端末・初回通信の保証ではありません。初回は集計データと標高タイルの通信時間が加わり、回線、画面範囲、端末によって数秒以上かかります。画面の処理時間は地図背景の完成を含まない解析時間です。物理スマートフォンの性能保証ではありません。

独立した全画素の球面距離判定と累積和計算を比較する自動検査は `tests/area.test.mjs`。元データとの地域別照合は `scripts/check_area_accuracy.py` です。東京・函館の100/300km、父島・稚内の300kmの6条件では、ズーム8〜10の事前集計と国内ズーム12＋国外ズーム8の全画素直接合計との差は最大0.017mでした。この値は当該6条件の集計誤差であり、全国の上限、元の標高や海岸線の精度を保証しません。

## データと通信

- 標準地図・淡色地図・陰影起伏図: 国土地理院「地理院タイル」
- 標高: 国土地理院「標高タイル（DEM1A、DEM5A、DEM5B、DEM5C、DEM10B、DEMGM）」
- 解析: すべて利用者のブラウザ内で実行

背景地図は正式提供範囲のズーム18まで表示します。色別標高図はズーム15、陰影起伏図はズーム16が配信上限のため、それより拡大した画面では同じタイルを拡大表示します。標高判定は上記の円内平均の定義に従います。地図上には着色格子のおおよその間隔を表示し、元データの画素間隔は補助状態として区別します。色別標高図の海域部は海上保安庁海洋情報部の資料を使用して作成されています。

標高タイルが404で提供されていない場合は欠測として扱いますが、通信失敗、サーバーエラー、PNG以外の応答は欠測へ置き換えません。解析を停止して画面上へ再試行案内を表示し、失敗結果をキャッシュしません。

本ツールは現在地の自動取得、住所入力、独自のアクセス解析を行いません。アプリ自身はCookieやWeb Storageに地点・設定を記録しません。地図・標高タイルの取得時には利用者のブラウザから国土地理院へ、事前集計データの取得時にはこのサイトの配信元（GitHub Pages）へ通信します。通信先にはIPアドレスと要求したデータのURLが伝わり、タイルURLから表示地域を推測できる場合があります。ブログとXには、利用者がリンクを押した時だけ移動します。

共有URLは「リンク取得」を押した時に生成し、表示中心・選択地点の座標と表示設定を端末のクリップボードへコピーします。座標はURLのクエリ部分にあるため、そのURLを開くとGitHub Pagesへ送信されます。ブラウザ履歴、配信元の通信記録、クリップボード・履歴の同期、共有先での保存に残る可能性があります。アプリが地点の保存機能を持たないことは、端末や配信元にも一切記録されないことを意味しません。個人宅などを共有する前にURLの内容を確認してください。

解析とPNG作成はブラウザ内で行い、作成したPNGをアプリが外部へアップロードすることはありません。PNG保存は端末へのダウンロードです。ブラウザの通常のキャッシュや配信元の記録を無効にする機能はなく、配信元のログ項目・保管期間を本ツールが制御・保証することもできません。

## ブランド画像

- ブログ導線とfaviconには、Bousai Wx Labで採用済みのユーザー提供サイトアイコンの512px公開版を、再加工せず同一bytesで自己ホストして使用
- 公開ファイルは `assets/bousaiwxlab-site-icon.png`、512×512px、RGB PNG、266,670 bytes、SHA-256 `f2258fc48adea8bdcf175699fb08b434b039c0aee83a4439c181741f3c2a4c9e`
- EXIF/XMPは色空間・画像寸法以外の人物名、位置情報、端末情報を含まないことを確認
- X導線は[公式ブランドツールキット](https://about.x.com/ja/who-we-are/brand-toolkit)の黒地・白ロゴ表現に合わせたベクター形状を、リンク識別用途だけに使用
- Open Graph／Xカード画像はユーザー提供PNGを無加工で自己ホストし、`assets/terrain-depression-share-card.png`、1774×887px、RGB PNG、2,717,426 bytes、SHA-256 `9a009f0503a2e3c0218965e4c4a673575101149a0bc5333aab693ba497376159`
- カード画像のPNGメタデータはsRGBと画像寸法だけで、人物名、位置情報、撮影日時、端末情報、テキストコメントを含まないことを確認

## ローカル確認

```bash
python3 -m http.server 8765
```

`http://127.0.0.1:8765/` を開きます。HTMLファイルをブラウザで直接開く方法では、安全制約により標高タイルを取得できません。

## 公開前検査

```bash
python3 scripts/build_release_manifest.py
python3 scripts/privacy_gate.py
node tests/terrain.test.mjs
node tests/area.test.mjs
```

`privacy_gate.py` は公開allowlist、ファイル内容、外部通信先、危険なブラウザAPI、Gitの全objectとcommit identityを検査します。ブランドPNGは許可したファイルのbytes、SHA-256、PNG構造、CRC、寸法、bit depth、color typeが完全一致する場合だけ認めます。集計データは個々のパス・bytes・SHA-256に加えて、圧縮ヘッダーに名称やコメントがないこと、展開サイズ、配列数、数値範囲、スキーマを検査します。検査不能または不一致は失敗として扱います。

## ライセンスと出典

本リポジトリの独自コードについて、明示的な利用許諾は設定していません。地理院タイルは国土地理院コンテンツ利用規約に従って利用してください。地図画面には出典を常時表示しています。仕様は[標高タイル](https://maps.gsi.go.jp/development/demtile.html)と[標高値の求め方](https://maps.gsi.go.jp/development/hyokochi.html)を参照してください。

集計データの再生成はNumPyとPillowを利用し、公開リポジトリ外の原本キャッシュを指定して、順に実行します。

```bash
python3 -B scripts/build_area_data.py --cache ../private/area-source-cache
python3 -B scripts/build_global_area_data.py --cache ../private/area-source-cache
python3 -B scripts/check_area_accuracy.py --cache ../private/area-source-cache
python3 -B scripts/register_area_release.py
python3 -B scripts/build_release_manifest.py
```
